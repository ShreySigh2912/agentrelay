# AgentRelay

Self-hosted AI agent gateway for WhatsApp, Telegram & Discord. Connect AI providers like Google Gemini, Anthropic Claude, and OpenAI to your instant messaging platforms seamlessly.

## Features
- Connect to WhatsApp, Telegram, and Discord
- Use top tier AI models via Google Gemini, Anthropic Claude, and OpenAI

## Quick Start
```bash
npm install -g @shrey_singh/agentrelay
agentrelay onboard
agentrelay gateway
```
